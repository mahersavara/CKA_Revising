# Kỹ năng Đọc đề CKA: Phương pháp "Trích xuất Từ khóa Cốt lõi" (Keyword Extraction)

Trong kỳ thi CKA, đề bài thường rất dài và viết bằng tiếng Anh. Chỉ cần bỏ sót một tiểu tiết (như sai namespace, gõ thiếu cờ read-only, đặt sai tên container) là toàn bộ câu hỏi sẽ bị chấm **0 điểm**. 

Dưới đây là phương pháp giúp bạn phân tích đề thi thành các thông số kỹ thuật (Inputs) một cách khoa học.

---

## 📋 Khung Phân Tích Đề CKA (5 nhóm thông tin cốt lõi)

Khi đọc bất kỳ câu hỏi CKA nào, hãy chuẩn bị giấy nháp (hoặc phần Note trên giao diện thi) và chia thành 5 nhóm thông số sau:

1. **Target Object (Đối tượng & Tên gọi):** Loại tài nguyên cần tạo (Pod, Deployment, Service, PV...) và Tên chính xác của nó.
2. **Namespace (Không gian tên):** Rất quan trọng! Nếu đề bài không nói gì thì mặc định là `default`. Nếu có nói, phải chuyển ngữ cảnh hoặc ghi rõ `-n <namespace>`.
3. **Container Specifications (Thông số Container):** Số lượng container, Tên container, Image, Biến môi trường (`env`), Lệnh chạy (`command`/`args`).
4. **Storage & Volumes (Ổ đĩa & Gắn kết):** Loại volume (PVC, HostPath, EmptyDir, Secret...), Tên volume, và Thư mục gắn kết (`mountPath`), chế độ (`readOnly`).
5. **Network / Port (Mạng & Cổng):** Cổng kết nối (Service Port, TargetPort, NodePort), giao thức (TCP/UDP), NetworkPolicy rules.

## 🔍 Case Study: Phân tích đề bài cụ thể

### 📝 Đề bài gốc:
> "Create a Pod **mc-pod** in the **mc-namespace** namespace with **three containers**. The **first container** should be named **mc-pod-1**, run the **nginx:1-alpine** image, and set an environment variable **NODE_NAME** to the **node name**. The **second container** should be named **mc-pod-2**, run the **busybox:1** image, and **continuously log the output of the date command to the file /var/log/shared/date.log every second**. The **third container** should have the name **mc-pod-3**, run the image **busybox:1**, and **print the contents of the date.log file generated by the second container to stdout**. Use a **shared, non-persistent volume**."

---

### ✍️ Bảng Trích Xuất Bộ Tham Số (Inputs):

| Nhóm thông tin | Từ khóa trong đề bài | Thông số kỹ thuật tương ứng |
| :--- | :--- | :--- |
| **1. Target Object** | "Create a Pod **mc-pod**" | `kind: Pod`, `name: mc-pod` |
| **2. Namespace** | "in the **mc-namespace** namespace" | `namespace: mc-namespace` (Nhớ lệnh tạo: `k create ns mc-namespace`) |
| **3. Container 1** | "named **mc-pod-1**", "**nginx:1-alpine**", "env variable **NODE_NAME** to the **node name**" | - Name: `mc-pod-1`<br>- Image: `nginx:1-alpine`<br>- Env: `NODE_NAME` lấy từ Downward API (`spec.nodeName`) |
| **4. Container 2** | "named **mc-pod-2**", "**busybox:1**", "**continuously log... to /var/log/shared/date.log every second**" | - Name: `mc-pod-2`<br>- Image: `busybox:1`<br>- Command: `while true; do date >> /var/log/shared/date.log; sleep 1; done` |
| **5. Container 3** | "name **mc-pod-3**", "**busybox:1**", "**print... date.log... to stdout**" | - Name: `mc-pod-3`<br>- Image: `busybox:1`<br>- Command: `tail -f /var/log/shared/date.log` (Lệnh stream log ra stdout) |
| **6. Storage** | "Use a **shared, non-persistent volume**" | - Loại volume: `emptyDir: {}`<br>- Mount path (Container 2 & 3): `/var/log/shared` |

---

## 💡 Mẹo nhỏ khi làm bài thi:
* **Gạch chân/Highlight ảo:** Khi thi, em có thể bôi đen chữ trên đề bài để highlight các thông số như Tên, Image, Namespace.
* **Tạo Namespace trước tiên:** Ngay khi thấy từ khóa về namespace, hãy chạy lệnh tạo namespace đó trước để tránh việc quên gắn `-n` hoặc quên tạo namespace làm lệnh apply bị lỗi.
